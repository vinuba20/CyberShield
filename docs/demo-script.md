# Demo script

This demo uses only synthetic fixtures and generated data. It verifies the implemented parser and evaluation code without implying that the missing import/repository workflows are available in the app.

## 1. Build and test

From the repository root:

```powershell
mvn package
mvn test
```

Expected: Maven builds the Java 21 project and the JUnit suite completes successfully.

## 2. Launch the desktop shell

```powershell
mvn javafx:run
```

Show the CyberShield dashboard. Until concrete event/incident repositories and a dashboard data provider are added, it displays that dashboard data is unavailable. It should not show seeded or fabricated incidents.

## 3. Parse the equipment-alarm sample

Open [`data/sample/equipment-alarms.csv`](../data/sample/equipment-alarms.csv) and [`docs/data-formats.md`](data-formats.md). Point out the synthetic comment, header, five fields, and timestamp format. The sample rows are accepted by `EquipmentAlarmCsvParser`; the running UI has no file chooser/import integration yet. [`data/sample/auth.log`](../data/sample/auth.log) is synthetic and illustrative only; there is no authentication parser to load it.

The parser and checked-in CSV sample are covered by `EquipmentAlarmCsvParserTest` and `EquipmentAlarmCsvSampleTest`. To run that focused verification:

```powershell
mvn -Dtest=EquipmentAlarmCsvParserTest,EquipmentAlarmCsvSampleTest test
```

## 4. Explain root-cause training/evaluation

The implemented API is `RootCauseEvaluation.evaluate(trainingSeed, testSeed, cascadesPerDataset, skewTolerance)`. It evaluates 0, 1, and 3 seconds of injected skew and trains a separate ranker only from each training split. The returned `EvaluationReport.toTable()` string contains measured baseline/ranker top-1 and top-3 counts and accuracy.

For a deterministic test-backed example, run:

```powershell
mvn -Dtest=RootCauseEvaluationTest,SyntheticCascadeGeneratorTest test
```

The actual sample report should be generated by calling the API for the chosen seeds/count; do not copy expected accuracy values from a test or claim the ranker wins unless the measured result shows that.
There is no evaluation CLI or dashboard action wired to this API yet; the test command validates the API but does not produce a user-facing report.

## 5. State the limitations

Explain that all cascade data is synthetic, the generated cascade structure determines what the ranker can learn, the live app has no historical-incident provider to train its Spring ranker, and no file import or incident persistence pipeline currently connects the sample to the dashboard.
